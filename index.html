Mind Cipher

A logic-based code-breaking puzzle game for iOS

Guess the hidden color code using feedback from each attempt. Green means correct position, orange means right color wrong spot, red means not in the code.

  • Classic Missions — 120 progressively harder levels from Beginner to Master
  • Lie Missions — 120 levels where one feedback per round is fake. Spot the contradiction.
  • Daily Challenge — A new puzzle every day with Game Center leaderboards
  • Smart Notes — Mark eliminated (✗) and confirmed (✓) colors on the board
  • Duel Mode — One player sets the code, the other cracks it
  • Challenge a Friend — Send a custom puzzle via link
  • Free Play — Customize code length, colors, attempts, and time limits
