Is Mind Cipher free?

Yes to start. Daily Challenge, Duel, notes, hints, the first 40 Classic missions, and the first 80 Lie missions do not require a purchase. Pro is a $2.99 one-time unlock for the rest of both campaigns, Free Play, and the custom editor. There is no subscription and no advertising.

What is Lie Mode?

Each round, one feedback row is false. The rest are true. You have to catch the contradiction instead of trusting every clue. Classic mode never does this.

How do I restore Pro?

Open Settings in the app and tap Restore Purchases. Apple handles the receipt. Use the same Apple ID you bought with.

Does it need an account?

No. Progress is stored on the device. Game Center is optional, for daily leaderboards. We do not run a server with your game data.

Is there an iPad version?

The current build is iPhone only.

How do I send feedback?

Use the speech-bubble button on the home screen, or the Support row in Settings. That opens GitHub or your mail app. Issues on GitHub are public, so leave out anything you want private.

Where is the privacy policy?

Read the privacy policy. Short version: no background collection, no third-party ads or analytics.
