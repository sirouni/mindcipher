  1. 1

    Place your pegs.

    Pick colors into the slots and submit the analysis. Cases run from 4 pegs and 6 colors up to longer codes with 8.

  2. 2

    Read the marks.

    Each submitted row comes back with four ink marks. The marks never say which peg they refer to. That gap is the puzzle.

    right color, right slot right color, wrong slot not in the code at all

  3. 3

    Spot the fake.

    Classic cases always report honestly. Lie cases fake one row per case, so a clean deduction can still walk you into a wall. Find the two rows that contradict each other, then throw the bad one out.

The app

Classic cases

240 cases from beginner to master, each a numbered sheet in the file. The attempt counter sits top-right; the marks are pure ink — dot, ring, dash — so they never depend on color.

  • Every past analysis stays on the sheet for cross-referencing.
  • Notes on the board mark eliminated and confirmed colors.
  • A Shape Marks setting gives every color its own outline.
  • First 40 cases are free.

Lie cases

A separate 240-case file. Same boards, one faked report per case, and a red stamp that reminds you not to trust the page.

  • Only one row per case is faked — never two.
  • Attempt budgets are looser here, because you will burn analyses proving a lie.
  • First 80 cases are free.

Today's Case

One puzzle a day, identical for everybody. The settings are published before you start — code length, color count, attempt budget, whether repeats are allowed. Top Secret days are lie cases.

  • Streak and total are kept in a ledger on the device.
  • Closed days stay stamped on the calendar; a home-screen widget shows today's status.
  • Free, always.
