One round, start to finish.

  1. 1

    Place your pegs.

    Pick colors into the slots and submit. Levels run from 4 pegs and 6 colors up to longer codes with 8.

  2. 2

    Read the report.

    Each submitted row comes back with four marks. The marks never tell you which peg they refer to. That gap is the puzzle.

    right color, right slot right color, wrong slot not in the code at all

  3. 3

    Spot the fake.

    Classic mode always reports honestly. Lie Mode fakes one row per round, so a clean deduction can still walk you into a wall. Find the two rows that contradict each other, then throw the bad one out.

The app

Classic Missions

240 levels from beginner to master. The attempt counter sits top-right; the legend stays on screen so you never have to remember what a triangle means.

  • Every past guess stays visible for cross-referencing.
  • Rows you have not used yet are numbered and greyed.
  • First 40 levels are free.

Lie Missions

A separate 240-level campaign. Same boards, one faked clue per round, and a red banner that reminds you not to trust the page.

  • Only one row per round is faked — never two.
  • Attempt budgets are looser here, because you will burn guesses proving a lie.
  • First 80 levels are free.

Daily Challenge

One puzzle a day, identical for everybody. The settings are published before you start — code length, color count, attempt budget, whether repeats are allowed.

  • Streak and total are tracked on the device.
  • Past days stay on the calendar.
  • Free, always.
